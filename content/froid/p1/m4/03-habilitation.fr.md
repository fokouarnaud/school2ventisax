## L'habilitation électrique

Le frigoriste intervient comme électricien sur divers équipements électriques et doit être informé des risques électriques. C'est l'habilitation électrique qui reconnaît qu'une personne est capable d'effectuer ce type d'opérations en toute sécurité. Il existe plusieurs niveaux d'habilitation selon le domaine de tension et le personnel.

| Domaine de tension (1re lettre) | Qualification du personnel (indice) | Nature de l'opération (2e lettre) |
|---|---|---|
| **B** : basse tension | **0** : opérations d'ordre non électrique | **T** : travaux sous tension |
| **H** : haute tension | **1** : exécutant d'ordre électrique | **V** : travaux au voisinage |
| | **2** : chargé de travaux | **N** : nettoyage sous tension |
| | **C** : consignation | **X** : spéciales |
| | **R** : intervention d'entretien et de dépannage | |
| | **S** : intervention de remplacement et de raccordement | |
| | **E** : opérations spécifiques | |
| | **P** : photovoltaïque | |

## Exemples d'habilitations

- **B0, H0, H0V exécutant** : personne habilitée à effectuer des travaux d'ordre non électrique dans un environnement électrique.
- **B0, H0, H0V chargé de chantier** : personne qui dirige une équipe réalisant des travaux non électriques à proximité d'un risque électrique (chef d'équipe de chantier, responsable d'entretien…).
- **BS** : opérations électriques simples (remplacement à l'identique de fusibles ou d'appareils, raccordement d'un matériel électrique à un circuit). Pour le personnel non expérimenté, l'habilitation BS s'accompagne d'un complément de connaissances (bases du câblage, lecture de plans…).
- **BE manœuvre, HE manœuvre** : manœuvres d'exploitation courantes des installations basse ou haute tension (réarmement d'une protection).
- **BC** : chargé de consignation.
- **BR** : chargé d'intervention ; permet par exemple d'effectuer des dépannages, des raccordements sous tension, des essais et des mesures.
- **En basse tension** : par exemple B1, B1V, B2, B2V essai, BR, BC, BE essai, mesure, vérification.
- **En haute tension** : par exemple B1, B2, BR, BC, H1, H2, HC, HE.
- **B1** : électricien qui travaille hors du voisinage des pièces nues sous tension et agit toujours sur instruction.
- **B1V** : mêmes tâches que B1, mais au voisinage des pièces nues sous tension.
