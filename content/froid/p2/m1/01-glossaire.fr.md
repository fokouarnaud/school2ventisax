Le cours est bilingue. Ce glossaire donne le terme anglais employé dans la version anglaise du cours, selon le vocabulaire de la CEI (Commission électrotechnique internationale) et l'usage britannique. Les règles d'installation citées viennent de la norme française **NF C 15-100**, proche pour l'essentiel de la norme internationale **IEC 60364**.

| Français | Anglais (CEI) |
|---|---|
| Phase (L) | Line (L) |
| Neutre (N) | Neutral (N) |
| Conducteur de protection, terre (PE) | Protective earth (PE) |
| Tension | Voltage |
| Intensité du courant | Current |
| Résistance | Resistance |
| Puissance | Power |
| Courant alternatif, courant continu | Alternating current (AC), direct current (DC) |
| Disjoncteur divisionnaire | Miniature circuit breaker (MCB) |
| Interrupteur ou disjoncteur différentiel | Residual current device (RCD) |
| Disjoncteur de branchement | Main incoming circuit breaker |
| Tableau de répartition | Consumer unit |
| Fusible, coupe-circuit | Fuse |
| Sectionneur porte-fusible | Fuse switch disconnector |
| Relais thermique | Thermal overload relay |
| Contacteur | Contactor |
| Bouton-poussoir | Push button |
| Simple allumage | One-way switching |
| Double allumage | Two-gang one-way switching (double switch) |
| Va-et-vient | Two-way switching |
| Télérupteur | Impulse relay |
| Minuterie | Staircase timer |
| Horloge, interrupteur horaire | Time switch |
| Boîte de dérivation | Junction box |
| Goulotte | Cable trunking |
| Schéma architectural | Architectural (layout) plan |
| Schéma développé | Wiring diagram |
| Schéma unifilaire | Single-line diagram |
| Schéma multifilaire | Multi-line diagram |
| Pince ampèremétrique | Clamp meter |

Les couleurs de fils sont celles du support : phase rouge, brune ou noire ; neutre bleu ; protection vert et jaune. Le distributeur d'énergie cité est **Eneo**.
