## Les outils de l'électricien

| Outil | Usage |
|---|---|
| Burin | Outil en acier qui permet de réaliser des saignées et des cassés dans les murs, en douceur |
| Poinçon | Laisse une marque dans une pièce, ou la perce |
| Massette | Masse qui sert à frapper un autre outil, notamment le burin et le poinçon |
| Pince à dénuder | Retire l'isolant des conducteurs |
| Pince coupante | Coupe les câbles |
| Pince à long bec | Saisit et place les conducteurs dans les zones étroites |
| Pince universelle | Saisit, serre, tord et coupe : la pince à tout faire de l'électricien |
| Jeu de tournevis | Tournevis plats et cruciformes, les deux formes les plus utilisées ; ils servent à visser et dévisser les appareils électriques |
| Cordeau de traçage | Trace des lignes droites pour aligner et mettre les équipements à niveau |
| Niveau à bulle | Vérifie qu'un équipement est fixé droit sur une surface plane |
| Perceuse électrique | Facilite le perçage et les saignées dans les poutres et les poteaux |
| Meuleuse | Facilite les saignées dans les murs et les sols déjà crépis |
| Testeur de phase | Identifie le conducteur de phase sur une installation sous tension |

**À retenir** : les tournevis de l'électricien sont toujours isolés sur toute la longueur de la tige.
