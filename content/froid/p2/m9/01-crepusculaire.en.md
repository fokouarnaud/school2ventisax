## Target competence

By the end of this module, the learner should be able to:

- define a twilight switch (<span lang="fr">interrupteur crépusculaire</span>) and a motion detector (<span lang="fr">capteur de mouvement</span>);
- explain how they work;
- identify the connection terminals and the setting controls;
- understand the basic wiring diagrams;
- set the devices and diagnose common faults.

## Definition

A twilight switch is a device that automatically switches lighting according to the ambient light level. It usually uses a light-sensitive cell (photocell).

## How it works

- When the light level falls, the device switches the lamp on at the set threshold.
- When the light level rises, the device usually switches the lamp off.

Some models have a time delay or hysteresis to avoid repeated switching when the light changes for a moment.

## Uses

- Lighting of yards, gardens and paths
- Street and car park lighting
- Facade and sign lighting
- Outdoor lighting of buildings

## Common terminals

| Terminal | Name | Usual function |
|---|---|---|
| L | Line | Supplies the device |
| N | Neutral | Supplies the device |
| L' / OUT | Switched output | Controls the lamp |
| PE | Protective earth | Protects the luminaire |

**Important**: terminal marking varies between manufacturers. Some models have three wires, others four or more. Always follow the wiring diagram in the instructions. A volt-free (dry) contact output is wired differently from an output that delivers a switched line.

|---|---|
| F1 | Circuit breaker protecting the circuit |
| B1 | Twilight switch (light-sensitive cell) |

| E1 | Lamp or luminaire |

## Connection

1. Switch off the supply, lock it off and check that the circuit is dead.
2. Connect the protected line to L and the neutral to N, if the model requires it.
3. Connect the switched output to the line terminal of the lamp.
4. Connect the other terminal of the lamp to neutral.
5. Connect the protective conductor (PE), present at every lighting point, to the earth terminal of a class I luminaire (NF C 15-100).

## Setting

**Light threshold**: the threshold setting decides at what light level the lighting switches on or off. A higher threshold usually switches on while it is still fairly light; a lower threshold waits for darker conditions. The exact behaviour depends on the model.

**Time delay**: when available, the time delay postpones switching so that the device does not react to brief changes in light.

**Setting procedure**

1. Check the wiring and protective devices against the instructions.
2. Set the light threshold as required.
3. Test darkness detection as described in the instructions.
4. Check that the lamp switches on, then off when the light level rises.
5. Adjust the setting if necessary.
