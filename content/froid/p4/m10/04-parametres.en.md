Parameters show the condition and correct operation of the equipment.

| Single-phase | Three-phase |
|---|---|
| Winding test | Winding test |
| Capacitor test | Check of the connection |
| Supply voltage | Supply voltage, between each phase |
| Starting current | Starting current |
| Rated current | Rated current, on each phase |

Currents are measured with a current clamp (<span lang="fr">pince ampèremétrique</span>), voltage with a multimeter.

**Analysis**: compare each value with the rating plate.

| Finding | Possible cause |
|---|---|
| Voltage more than 10% below the plate | Weak supply, undersized cable |
| Running current above the plate | HP too high, dirty condenser, overcharge, low voltage |
| Running current well below | Lack of refrigerant, compressor no longer pumping |
| Different currents on the three phases | Weak phase, loose connection, faulty winding |
| Starting current held, protector trips | Faulty start relay or capacitor |
